# EduVest公式ホームページ

教育・AI研修・アプリ開発・業務自動化のサービスと制作例を紹介する、日本語・英語対応の静的Webサイトです。

公開先：
- 日本語：https://eduvest-technologies.pages.dev/
- English：https://eduvest-technologies.pages.dev/en/

## 使用技術
HTML、CSS、JavaScript、PNG画像、Google Fonts、Cloudflare Pagesを使用しています。CSSと画像拡大用JavaScriptは各HTMLに含まれ、ビルド処理は不要です。

## ファイル構成
- `index.html`：日本語ページ
- `en/index.html`：英語ページ
- `img/`：掲載画像14点
- `_headers`：配信用HTTPヘッダー設定

## 制作・確認の流れ
掲載内容と素材を整理し、日本語・英語ページを作成します。表示、画像、リンク、スマートフォン幅を確認し、Owner承認後にCloudflare Pagesへ直接アップロードします。Git連携は使用していません。

## 情報の取り扱い
公開用の代表者紹介と外部プロフィールへのリンクを含みます。2026年10月29日の対象17ファイルの点検では、認証情報、会員・生徒・保護者の名簿や連絡先、台帳、Googleフォーム・スプレッドシートの編集用URL、子どもの顔が写った実写写真は確認されませんでした。

外部リンク先の内容は、この点検の対象外です。素材の利用・再配布条件を一律に許諾するものではありません。
